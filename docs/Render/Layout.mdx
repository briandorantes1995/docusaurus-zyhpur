## Parametros Layout
Los siguientes parametros sirven para definir el Layout del pdf (tamano, orientacion)


## format -- string

```
Tamaño del PDF: A0-A5, Letter, Legal, Tabloid, Ledger. Default: A4
```

<MonacoSnippetViewer
  fileName="api.js"
  language="javascript"
  highlightLines={[2,9]}
  code={`const response = await fetch('https://api.zyphur.me/render/pdf', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer TU_API_KEY', 
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://example.com/reporte',
    format: 'Letter' //en caso de no especificar el default es A4
  })
});
const blob = await response.blob();

const url = URL.createObjectURL(blob);
window.open(url);`}
/>


## width  height -- string

:::warning
**No usar junto con format**  
:::

```
width Ancho personalizado (ej: '210'mm)
```
```
height Alto personalizado (ej: '297'mm)
```

<MonacoSnippetViewer
