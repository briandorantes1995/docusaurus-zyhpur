## Parametros de los logos

Los logos son elementos que se pueden agregar a un pdf generado (ya sea html, url o template)

## logo_image -- string

```
logo como base64 (data:image/png;base64,... o data:image/jpeg;base64,...).
si no se especifica posicion siempre tomara como Default:top-left
```
## logo_position -- string

```	
Posición del logo: top-left, top-right, bottom-left, bottom-right, top-center,bottom-center. Default: top-left.
```

## logo_x -- number	

```
Desplazamiento horizontal en puntos PDF desde la posición base(Default:top-left).
```
## logo_y -- number	

```
Desplazamiento vertical en puntos PDF desde la posición base(Default:top-left).

```
