# Parametros requeridos
Por defecto requiere al menos uno de los siguientes parametros para funcionar,
hablaremos mas a detalle sobre cada parametro en las siguientes secciones

# Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: application/json**
:::

:::tip
La Apikey es generada en la seccion de apikeys del dashboard , una vez registrado puedes comenzar a usarla
Si aun no te has registrado, registrate para recibir 50 creditos gratis 
:::

## html_template

HTML con sintaxis Handlebars. Las `{{ }}` serán reemplazadas con los valores de variables.

<MonacoSnippetViewer
  fileName="api.js"
  language="javascript"
  highlightLines={[2,9]}
  code={`const response = await fetch('https://api.zyphur.me/render/pdf', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer TU_API_KEY', 
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    html_template: '<h1>Hola {{nombre}}</h1>',
    variables: { nombre: "Zed" } // Variables a mostrar dentro del template
  })
});

const data = await response.json();`}
/>
