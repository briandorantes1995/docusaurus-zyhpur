## Parametros de las firmas

Las firmas son elementos que se pueden agregar a un pdf generado (ya sea html, url o template)

## signature_image	-- string

```
Firma como base64 (data:image/png;base64,... o data:image/jpeg;base64,...).
si no se especifica posicion siempre tomara como Default:top-left
```
## signature_position	-- string

```	
Posición de la firma: top-left, top-right, bottom-left, bottom-right, top-center,bottom-center. Default: top-left.
```

## signature_x	-- number	

```
Desplazamiento horizontal en puntos PDF desde la posición base(Default:top-left).
```
## signature_y	-- number	

```
Desplazamiento vertical en puntos PDF desde la posición base(Default:top-left).

```
