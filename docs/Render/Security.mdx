# Parametros para Seguridad


## store -- boolean
```
Almacenar el PDF y devolver URL de descarga (24h). Default: false (devuelve binario)
```
:::info
Tu pdf sera almacenado por 24h (podras descargar cuantas veces sea necesario), 
por defecto store no esta habilitado, dado que no mantenemos informacion de ningun pdf generado.
:::

:::tip
Ademas la respuesta devolvera metricas(tiempo,creditos usados)
:::

<MonacoSnippetViewer
  fileName="security.js"
  language="javascript"
  highlightLines={[2,9]}
  code={`const response = await fetch('https://api.zyphur.me/render/pdf', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer TU_API_KEY', 
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://example.com/reporte',
    format: 'Letter',
    store:true //en caso de no especificar el default es false
  })
});
const data = await response.json(); //respuesta con url de descarga y metricas , se usa asi porque no devuelve el pdf directamente, si no que lo almacena y devuelve la url de descarga (valida por 24h)`}

## password --	string 

```
Contraseña requerida para abrir el PDF. Default: sin contraseña.
```

:::tip
Para maxima privacidad, usar en conjunto (password,no_copy,no_print)
:::

:::warning
Deberas ingresar la contraseña cada que abras el pdf (util para informacion sensible)
:::

<MonacoSnippetViewer
  fileName="security.js"
  language="javascript"
  highlightLines={[2,9]}
  code={`const response = await fetch('https://api.zyphur.me/render/pdf', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer TU_API_KEY', 
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://example.com/reporte',
    format: 'Letter',
    password : '12345' //se pediria cada que se abra el pdf, resguardar
  })
});

const blob = await response.blob();

const url = URL.createObjectURL(blob);
window.open(url);`}
/>
