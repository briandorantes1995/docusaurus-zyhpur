# Inicio Rapido

La forma más sencilla y rápida de probar la API.

## Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: application/json**
:::

:::tip
La API Key es generada en la sección de apikeys del dashboard. Una vez registrado puedes comenzar a usarla.
Si aún no te has registrado, regístrate para recibir 50 créditos gratis.
:::
