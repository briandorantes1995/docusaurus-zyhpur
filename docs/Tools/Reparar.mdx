# Herramientas

## Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: multipart/form-data**
:::

## Repararr PDF


## Parametros

```
file -- File[]
```

```
store -- boolean (opcional)
```

:::info
Sanea la estructura interna de un PDF dañado o con referencias corruptas usando qpdf
:::

const formData = new FormData();

// Archivo PDF a reparar
formData.append('file', fs.createReadStream('documento.pdf'));

const response = await fetch('https://api.zyphur.me/api/tools/pdf/repair', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer TU_API_KEY'
    Content-Type: 'multipart/form-data',
  },
  body: formData
});

// Respuesta por defecto: PDF binario
