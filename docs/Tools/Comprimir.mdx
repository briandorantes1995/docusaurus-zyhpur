# Herramientas

# Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: multipart/form-data**
:::

## Comprimir PDF


# Parametros

```
file -- File[]
```

```
quality -- string
```

```
store -- boolean (opcional)
```

:::tip
- `screen` → máxima compresión, menor calidad  
- `ebook` → balance (recomendado)  
- `printer` → alta calidad  
- `prepress` → calidad máxima  
:::

const formData = new FormData();

// Archivo PDF a comprimir
formData.append('file', fs.createReadStream('documento.pdf'));

// Nivel de compresión (opcional)
formData.append('quality', 'ebook');

const response = await fetch('https://api.zyphur.me/api/tools/pdf/compress', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer TU_API_KEY'
    Content-Type: 'multipart/form-data',
  },
  body: formData
});

// Respuesta por defecto: PDF binario
const buffer = await response.arrayBuffer();
`}
