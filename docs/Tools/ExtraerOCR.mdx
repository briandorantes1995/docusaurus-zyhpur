# Herramientas

## Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: multipart/form-data**
:::

## Extraer Informacion estructurada de un PDF con OCR


## Parametros

```
file -- File[]
```

```
store -- boolean (opcional)
```
:::info
- `true` → para guardar el JSON en CDN y recibir URL. Default: JSON directo.
:::
