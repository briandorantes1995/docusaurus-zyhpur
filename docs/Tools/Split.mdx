## Separar Pdfs

## Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: multipart/form-data**
:::

:::warning
Si el documento no tiene las paginas arroja un error asi
El documento solo tiene 4 páginas. Solicitaste la página 7.
:::


```
Extrae páginas específicas de un PDF usando rangos flexibles.
```

## Parametros
```
file -- File[]
```
```
pages -- string Páginas a extraer (índice desde 1). Ejemplos: '1,3,5' · '2-6' · '1,3,5-7,10'.
```
```
store -- boolean (opcional)
```

<MonacoSnippetViewer

const formData = new FormData();

// Solo un archivo para extraer páginas
formData.append('file', fs.createReadStream('documento.pdf'));

// Páginas a extraer (ejemplo)
formData.append('pages', '1,3,5-7');

const response = await fetch('https://api.zyphur.me/api/tools/pdf/extract', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer TU_API_KEY',
   'Content-Type': 'multipart/form-data',
  },
  body: formData
});

// Respuesta por defecto: PDF binario
const buffer = await response.arrayBuffer();
`}
/>

const formData = new FormData();

// Solo un archivo para extraer páginas
formData.append('file', fs.createReadStream('documento.pdf'));

formData.append('pages', '1,3,5-7');

const response = await fetch('https://api.zyphur.me/api/tools/pdf/extract', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer TU_API_KEY',
   'Content-Type': 'multipart/form-data',
  },
  body: formData
});


const data = await response.json();
console.log('PDF unido:', data.url);
`}
