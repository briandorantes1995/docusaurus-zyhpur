## Unir Pdfs

## Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: multipart/form-data**
:::

```
Unir 2 Pdfs de Manera Simple y rapida
```

## Parametros
```
file -- File[]
```
```
store -- boolean (opcional)
```


<MonacoSnippetViewer

const formData = new FormData();

formData.append('file', fs.createReadStream('contrato.pdf'));
formData.append('file', fs.createReadStream('anexo.pdf'));

const response = await fetch('https://api.zyphur.me/api/tools/pdf/merge', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer TU_API_KEY',
    'Content-Type': 'multipart/form-data',
  },
  body: formData
});

const buffer = await response.arrayBuffer();
`}

<MonacoSnippetViewer
  fileName="merge-pdf.js"

  highlightLines={[6,7,8]}
  code={`import fs from 'fs';

const formData = new FormData();

formData.append('file', fs.createReadStream('contrato.pdf'));
formData.append('file', fs.createReadStream('anexo.pdf'));

formData.append('store', true); // devuelve un url temporal del pdf generado, disponible por 24 horas

const response = await fetch('https://api.zyphur.me/api/tools/pdf/merge', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer TU_API_KEY',
    'Content-Type': 'multipart/form-data',
  },
  body: formData
});

const data = await response.json();
console.log('PDF unido:', data.url);
`}
/>
