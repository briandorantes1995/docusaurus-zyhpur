# Herramientas

## Headers requeridos en todas las peticiones:

:::info
**Authorization: Bearer TU_API_KEY**  
**Content-Type: multipart/form-data**
:::

## Optimizar PDF


## Parametros

```
file -- File[]
```

```
quality -- string
```

```
store -- boolean (opcional)
```

:::tip
- `screen` → máxima compresión, menor calidad  
- `ebook` → balance (recomendado)  
- `printer` → alta calidad  
- `prepress` → calidad máxima  
:::

:::info
Pipeline interno de optimización:
-- Reparar — qpdf reconstruye la estructura del PDF
-- Comprimir — Ghostscript reduce imágenes según quality
-- Linearizar — qpdf habilita Fast Web View (carga progresiva)
:::
